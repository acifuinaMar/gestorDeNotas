# Gestor de notas
## Características
- Autenticación con email y contraseña
- Autenticación con cuenta de Google
- Creación de notas
- Eliminación de notas
- Persistencia de datos

## Tecnologías utilizadas
- Firebase Hosting
- Firabase Firestore
- Firebase Authetication
- HTML5 + CSS3
- JavaScript
